#
# This file lists every package the code imports directly, pinned to the version in .venv_ut; requirements-lock.txt
# pins the full set (transitive dependencies included). Both must change together: after installing or upgrading a
# package, update its pin here and regenerate the lock with
#   pip freeze --exclude-editable | sed '1i --extra-index-url https://download.pytorch.org/whl/cu121' > requirements-lock.txt
# common/tests/test_environment.py fails when an installed version drifts from either file.
#
# Notes
# - numpy must stay < 1.24: OpenPCDet 233f849 still uses np.int / np.float / np.bool. The official scorer asks for
#   numpy >= 1.24 but runs unchanged on 1.23.5 (verified, see common/tests/test_official_parity.py).
# - setuptools < 70: torch 2.1's cpp_extension imports pkg_resources (needed to build OpenPCDet's CUDA ops).
# - OpenPCDet itself is not on PyPI: setup_venv_ut.sh clones commit 233f849 into $BDC_THIRD_PARTY and builds it.
# - The bdc26 package (common/) is installed in editable mode by setup_venv_ut.sh (pip install -e common).
# - open3d (engine G2-lite, R3) lives here too since 2026-10-13 (it was in a separate conda env, bdc-sim): installing it
#   changes no other pin; it brings its visualization stack (dash, plotly, pandas, scikit-learn, ...), pinned in the lock.
