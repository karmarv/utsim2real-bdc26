# Decisions log

One dated file per decision, organizer answer, legal answer or gate outcome, for example `2026-10-03-gate-A.md`.

Template:

```
# <date> <title>
Context: what was being decided and why now
Evidence: numbers (real-val per-class AP with intervals, proxy R, leaderboard ids), links to registry rows
Decision: what we do
Consequences: which flags, configs or plans change (update 02-STRATEGY.md Section 6 for gated branches)
```
