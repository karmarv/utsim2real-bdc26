**Transfer.** V2X followed the local numbers closely: pedestrian +0.012 on the leaderboard against +0.011 on B, realism +0.0065 against +0.0064 as packaged. On LUMPI the realism gain transferred at 1.5x the local one (+0.041 against +0.028): the gap between the local proxies and the hidden reference, which R1-R2 could not close by frame selection (S1 frames 0.906 locally, 0.891 on the server; EMD 1.53 against 1.65), is now 0.002 (EMD 1.28 against 1.30), so the static clutter adds structure where the test window has it. The LUMPI detection gains did not transfer: Truck +0.025 (0.5 x B), Bus +0.003, and Bicycle fell by 0.056, the second loss of a locally strong Bicycle change after S5 (-0.030).

**LUMPI diagnosis** (no test labels used): (1) at test size (frames resampled to the test window's 80 bicycles, 190 trucks, 25 buses) the R3 - S4 changes would lie in Bicycle -0.011 to +0.102, Truck +0.084 to +0.165, Bus +0.029 to +0.252 (90%), so the leaderboard values (-0.056, +0.025, +0.003) are not sampling noise; (2) on the 50 test frames the R3 portfolio emits 3.68 confident Bicycle boxes per frame (S4 3.16; 1.10 and 1.03 x their realval-A rates) against about 1.6 real bicycles per test frame (realval-A 4.84), and every Bicycle member fires 1-19% more on the test frames than on realval-A; (3) confident Bicycle boxes on real motorcycles are unchanged (0.47 -> 0.49 per realval-B motorcycle). As in S5, a more sensitive Bicycle detector meets a test window with a third of the bicycle density and more false positives on content the realval frames lack. Reverting LUMPI Bicycle because of these numbers would tune on the test set and is not done; the class stays a known exception to the local gates.

**Consequences.**
1. **Size realism needs physical limits:** any augmentation on top of real sizes must stay inside the real size range (`CLASS_MAX`); an anchor-free head will fit the longest training object onto real static structures.
2. **Real sizes blur classes the twin kept apart:** the UT bus asset and the short UT trucks were easy to separate; with real sizes, LUMPI Bus, Truck and Car need members that see both (the fusions do), and the per-class portfolio is what keeps a corpus change safe.
3. **Static hard negatives work on walkers:** confident static Person false positives fall by more than half in every LUMPI two-stage member. Person still did not enter the portfolio: with the larger final pool the best joint fusion candidate (A 0.473) gained only +0.004 on B. The next walker lever is ranking among these new members, not more hard negatives.
4. **The pooled condition belongs on final predictions:** inside `fuse` it passed the S5 Car fusion (P 1.00 before the score floors), on the final predictions it does not (P 0.64, the S5 diagnosis value); `route_predictions.py gate --vs <entry>` is the last step of every portfolio from R3 on.
5. **The upload gate uses the unclipped estimate:** V2X B-mAP passed 0.7, where the clip of the official formula would freeze the gate while the leaderboard mAP is 0.589.
6. **Open data gaps:** a tall static structure of the real LUMPI intersection (around (18, -28)) that the twin under-represents attracts long false trucks; LUMPI Cars 25 m or more from the nearest sensor stay at 0.6x the real density; long LUMPI trucks need free road the UT traffic rarely leaves. A `g1-v5` with long tall static negatives (walls, hedges, tree rows) is the follow-up candidate.
7. **Realism follows generator content:** the LUMPI realism gap to the hidden reference closed (0.002 instead of 0.015) once the twin got static structure; the next realism step is more of the real intersection's structure (walls, hedges, tree rows), which is also the remaining LUMPI Truck error.
8. **LUMPI Bicycle is locally unpredictable** in two uploads of two strategies (S5 -0.030, R3 -0.056, each after a local gain with pooled P 1.00): the test window holds about 1.6 bicycles per frame against 4.8 in realval-A. A later strategy that changes LUMPI Bicycle needs a gate on a test-window-like proxy (for example realval frames re-weighted to the test window's class counts) before it is trusted.
